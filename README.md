# Flow — Deposit & Withdraw Tracker

A clean, minimal transaction tracker that runs entirely in your browser. No backend, no accounts — just open and go.

## Features

- ➕ Add deposits and withdrawals with description and date
- 💰 Live balance, total deposited, and total withdrawn summary
- 🔍 Filter by all, deposits, or withdrawals
- 🗑️ Delete individual transactions
- 💾 Persists data in `localStorage` (survives page refresh)

## Usage

Just open `index.html` in any browser — no build step required.

```
git clone https://github.com/YOUR_USERNAME/flow-tracker.git
cd flow-tracker
open index.html
```

## Tech

Plain HTML, CSS, and vanilla JavaScript. Zero dependencies.
